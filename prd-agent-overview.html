PRD AGENT · PUBLIC OVERVIEW

PRD Agent
公开项目说明

一个面向企业产品文档的知识检索与问答项目。关键结论需要回到经过权限校验的文档证据，证据不足时明确说明边界。

一、项目目标

PRD Agent 的目标不是让大模型“凭经验回答”，而是让每个关键结论都能够回到经过权限校验的文档证据，并在证据不足时明确说明边界。

二、核心链路

  1. 文档处理：解析产品文档，保留标题、章节、版本和权限等必要信息。
  2. 分层召回：先定位可能相关的文档，再在候选文档内部检索章节和内容片段。
  3. 混合检索：结合关键词、向量检索和重排，降低只命中“语义相似但条件错误”内容的概率。
  4. 证据补全：根据问题补充父章节、相邻片段或相关文档，避免关键条件被切断。
  5. 回答控制：区分完整回答、部分回答、需要澄清、证据不足和无权限等状态。
  6. Trace 与评测：记录检索、重排和证据选择过程，并使用真实 Bad Case 做离线回归。

三、产品判断

企业知识问答的核心不是生成更流畅的文字，而是提高“找对文档、找全证据、使用正确版本、避免越权和不凭空补写”的稳定性。因此项目优先建设评测与证据链，再逐步增加复杂 Agent 能力。

四、当前实践重点

  • 建立覆盖不同问题类型的稳定评测集。
  • 完善文档目录、版本状态和知识治理。
  • 验证分层 Hybrid RAG 与重排策略。
  • 让答案中的关键事实可追溯到原文。
  • 通过同一批题目进行改动前后回归，避免局部提升造成其他问题退化。

五、公开范围

本页面只展示经过脱敏的产品思路、通用架构和评测方法。企业内部文档、业务数据、账号信息、权限配置、真实问答内容和私有源码不会公开。
