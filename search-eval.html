Agent 工作台

  1. 01
    自己找 Bad Case

    读取搜索体验、评测 Run 或抽样 Query，发现当前排序不好的地方。

  2. 02
    提出候选策略

    只在受控空间内尝试，比如字段权重、型号精确匹配、同义词扩展。

  3. 03
    Harness 比较

    同一批数据上跑优化前和候选策略，比较指标、样本和退化 Query。

  4. 04
    等待人工审批

    人只判断策略取舍；点击更新后，系统再自动写入版本化策略并验证。
