# Changelog

## 0.3.4 — 2026-08-28

- 移除 macOS 伴侣在全局鼠标抬起后自动注入 `Command+C` 并改写剪贴板的兼容回退，避免其他应用的悬浮窗失焦、关闭或误触命令。
- 仅通过只读 Accessibility 属性及 Web Text Marker 读取选区，并向上查找最多八层辅助功能父节点。
- 只有拖选、双击或按住 Shift 扩选才读取文本；普通单击不再复用旧选区，短时间重复事件会自动去重。
- 密码控件及其辅助功能祖先链一律跳过，不读取或记录敏感文本。
- 点击“学习”以外区域时立即关闭本应用悬浮窗，不再用延迟保护影响后续操作。
- 新增禁止全局键盘注入和剪贴板访问的安全回归测试。

## 0.3.3 — 2026-08-28

- 串行化扩展消息与存储写入，避免多标签页同时曝光、评分或添加知识时覆盖数据。
- 忽略同一天来自旧标签页的重复评分，避免阶段和复习次数被重复推进。
- 支持在普通网页的跨域及 `about:blank` iframe 中划词学习，提升在线文档和嵌入式编辑器兼容性。
- 来源地址只保留 HTTP(S) 的来源与路径，自动移除账号、查询参数和片段，避免令牌进入知识库。
- macOS 应用改为 Apple 芯片与 Intel 通用包；更新安装前会退出旧进程，并同时配置 Chrome、Chromium 和 Edge。
- Windows 安装脚本可自动定位常见的 Chrome 与 Edge 安装路径。
- 源码与发布包使用同一固定扩展 ID，移动安装目录后原生通信配置仍然有效。
- 下载包内部文件名改为跨平台安全的 ASCII，避免 Windows 解压中文安装文件名时乱码。

## 0.3.2 — 2026-08-27

- 修复达到曝光次数后，所有可用卡片会被逐步跳过并最终从左下角消失的问题。
- 一轮卡片全部曝光完成后自动开启下一轮；当天全部复习完成或主动关闭时仍保持空状态。
- 修复网页与 macOS 划词“学习”悬浮窗点击时被提前关闭的问题，并增加短暂点击保护、滚动重定位和自动收起。
- 新增按 `rotation`、`native`、`runtime`、`storage`、`ui` 模块独立开关的脱敏诊断日志，生产环境默认关闭。

## 0.3.1 — 2026-08-27

- 修复扩展重新加载后，旧网页触发 `Extension context invalidated` 未捕获异常的问题。
- 上下文失效时改为提示刷新网页，不再向 Chrome 错误页写入异常记录。

## 0.3.0 — 2026-08-27

- 新增网页与 macOS 跨应用划词“学习”按钮。
- 新增 NDCG、BM25、向量召回、Cross-Encoder 等搜索原理知识卡。
- 卡片改为紧凑正文展示，支持删除和关闭。
- 新增小、中、大三种卡片尺寸。
- 新增曝光 1～20 次后自动轮换。
- 移除“下一张”按钮；点击“记得”后直接进入下一张。
- 新增 macOS 与 Windows Release 下载包。
